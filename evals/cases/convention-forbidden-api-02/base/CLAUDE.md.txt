# entitlements

サブスクリプションの有効期限と、プランごとに使える機能を判定するライブラリです。

## 構成

- `src/domain/` … 判定ロジック。外界に触れません。
- `src/infra/` … 時刻・永続化・HTTP など、外界に触れる実装を置きます。

## 規約

- `src/domain/` では現在時刻を直接取得しない。
  `Date.now()` や `new Date()` を呼ばず、引数で受け取った `Clock` の `now()` を使う。
  期限判定のテストは時刻を固定して境界値を確かめるため、直接取得が混ざるとその case が実行時刻に依存して落ちるようになる。
  `Clock` の実装は `src/infra/clock.ts` にある。
- 日時の文字列表現は ISO 8601 (UTC) に統一する。
- 公開する構造体は `interface`、ユニオン型は `type` で定義する。
- 例外は `DomainError` の subclass で投げ、呼び出し側が種類で分岐できるようにする。
